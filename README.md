# D-Racer-Kit (SEA:ME)

D-Racer-Kit ROS packages developed for the SEA:ME program.

## Packages Included
- `battery` / `battery_msgs`: Battery status monitoring
- `camera`: Camera capture and streaming
- `control` / `control_pkg` / `control_msgs`: Vehicle control and actuator interface
- `joystick` / `joystick_msgs`: Teleoperation and gamepad control
- `line_pkg`: Lane detection and following
- `mission_planner_pkg`: Mission planning and state machine
- `monitor`: System and diagnostic monitoring
- `opencv`: Image processing utilities
- `stopline_pkg`: Stop line detection
- `topst_utils`: Hardware utilities
- `ufld_line_pkg`: Ultra Fast Lane Detection (UFLD) inference and training pipeline
- `yolo_pkg`: YOLO object detection
